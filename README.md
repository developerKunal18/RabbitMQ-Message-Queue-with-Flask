# RabbitMQ Message Queue with Flask

A Python project demonstrating asynchronous messaging using RabbitMQ.

## Features

- RabbitMQ producer
- RabbitMQ consumer
- Reliable message delivery
- Dockerized RabbitMQ

## Technologies Used

- Python
- RabbitMQ
- Pika
- Docker

## Installation

```bash
pip install -r requirements.txt
```
